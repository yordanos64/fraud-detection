# Notebooks Directory

This folder contains the complete, step-by-step development notebooks for the fraud detection pipeline:

* **eda-fraud-data.ipynb**: E-commerce data profiling and geolocation mapping.
* **feature-engineering.ipynb**: Temporal features and 30-minute device rolling velocity.
* **eda-creditcard.ipynb**: Bank transaction profiling and scaling.
* **modeling.ipynb**: Baseline Logistic Regression and Ensemble XGBoost training.
* **shap-explainability.ipynb**: Global and local SHAP feature explanations.
